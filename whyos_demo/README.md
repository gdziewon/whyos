# WhyOS Demo

Reference/demo firmware and functional tests for WhyOS.

### What

`whyos_demo` contains example board integration, a simple demo app (serial console + shell integration), and the functional tests that exercise the kernel features (scheduler, ITC primitives, lifecycle, etc.).
